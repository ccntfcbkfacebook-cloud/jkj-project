# Nestora Realty

A responsive bilingual (English and Telugu) real estate and home-loan enquiry website. The demo includes searchable Hyderabad property cards, an enquiry form, and a chat widget with interactive quick replies.

## Preview

Open `index.html` directly in a modern browser, or serve the folder locally:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`. No package installation or build step is required. The photos and web fonts load from external providers.

## Notes

The listings, bank references, ratings, and enquiry responses are demonstration content. The enquiry form validates and displays a local confirmation; connect it to a backend or CRM to receive real enquiries. The chat uses a small client-side scripted response set and does not connect to a live agent.
