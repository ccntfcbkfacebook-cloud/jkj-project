📖 How to connect Supabase Cloud (క్లౌడ్ డేటాబేస్ సెటప్ విధానం)

Real Cloud Database తో కనెక్ట్ చేయడానికి ఈ క్రింది 5 సులభమైన దశలను అనుసరించండి:

  1. supabase.com కి వెళ్లి ఉచిత ఖాతా సృష్టించి, కొత్త ప్రాజెక్ట్ క్రియేట్ చేయండి.
  2. Supabase లో Project Settings → API కి వెళ్లి మీ Project URL మరియు anon / publishable key కాపీ చేయండి.
  3. మీ ప్రాజెక్ట్‌లోని supabase-config.js ఫైల్ ఓపెన్ చేసి ఆ రెండు విలువలని పేస్ట్ చేయండి.
  4. Supabase డాష్‌బోర్డ్‌లో SQL Editor కి వెళ్లి, మీ ప్రాజెక్ట్‌లోని supabase-properties.sql కోడ్‌ను పేస్ట్ చేసి Run చేయండి.
  5. Authentication → Users కి వెళ్లి కొత్త అడ్మిన్ యూజర్‌ను క్రియేట్ చేసి, app_metadata: {"role": "admin"} సెట్ చేయండి.
